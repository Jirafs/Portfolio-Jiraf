Сервер хранит задачи и проверяет права участников. Войдите в локально запущенное приложение, создайте задачу и пригласите другого пользователя.

Аккаунты

Вход и выход, сессии, хеширование паролей. У каждого нового аккаунта — своё пространство.

Три роли

Владелец управляет участниками, редактор меняет задачи, наблюдатель читает доску.

Общие данные

SQLite сохраняет задачи между запусками. Конфликт устаревшей правки не затирает свежую версию.

Запустить у себя

GitHub Pages показывает эту страницу, но не исполняет Python. Для работы с аккаунтами нужен локальный сервер. Требуется Python 3.10 или новее; внешние пакеты не нужны. 

git clone https://github.com/Jirafs/Portfolio-Jiraf.git
cd Portfolio-Jiraf
python demos/orbit/server/main.py

Откройте http://127.0.0.1:8787. Создайте тестовый аккаунт, затем добавьте задачу. Для проверки ролей создайте второй аккаунт в другом браузере и добавьте его email в участники первого пространства.

Это локальный учебный сервер. Внешний хостинг, HTTPS, восстановление пароля и почтовые приглашения ещё не подключены.
