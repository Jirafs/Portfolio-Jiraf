# Jiraf Portfolio

Статический сайт для GitHub Pages: портфолио, педагогические материалы и четыре учебных демо разной сложности. Демо не создают реальные записи или заказы.

## Запуск и проверка

Требуется Node.js 22 или новее. Из корня репозитория:

```sh
npm ci
npm test
npm run build:cases
python -m http.server 8765 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8765/. Проверки охватывают синтаксис JavaScript и CSS, локальные ссылки, HTML ID, маршруты кейсов, модель Orbit, конфликты сохранения, корзину Pulse и существующие функции педагогических материалов. Они не заменяют проверку интерфейса в браузере.

`npm run format` форматирует основные изменяемые модули. `npm run optimize:images` пересоздаёт WebP из сохранённых оригиналов; `sharp` используется только при подготовке ресурсов. Шрифты размещены локально, лицензии — в `fonts/`.

## Кейсы

Данные и сценарии находятся в `script.js`, общий шаблон — `project.html`. После изменения выполнить `npm run build:cases` и сохранить обновлённые `cases/*.html`, `sitemap.xml`, `robots.txt`. Отдельные страницы содержат текст и метаданные до выполнения JavaScript. Старые адреса `project.html?project=...` поддерживаются.

## Демо

- Kosmetica: четыре страницы, услуги и демонстрация записи.
- FitClub Pro: пять страниц, фильтры расписания и локальный план.
- Pulse Merch: семь страниц; `cart-model.js` проверяет позиции и расчёты, `app.js` управляет интерфейсом. Корзина и избранное хранятся в localStorage, квитанция — в sessionStorage.
- Orbit Workspace: пять экранов; описание модулей — в `demos/orbit/README.md`. Серверное развитие вынесено в [отдельный план](docs/ORBIT_SERVER_PLAN.md).

## Перед публикацией

Проверить в браузере запись, план тренировок, оформление с PULSE10, редактор задач, конфликт двух вкладок, импорт/экспорт. На ширине 320–390 px проверить навигацию, формы и диалоги, а с клавиатуры — фокус, Escape и альтернативу перетаскиванию. При публикации не подменять пользовательские файлы и JSON-манифесты педагогического раздела тестовыми данными.

GitHub Pages обслуживает готовые статические файлы. После push дождаться успешного Pages deployment, затем открыть главную, один кейс и Orbit по публичному адресу.
