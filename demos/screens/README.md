# Скриншоты демонстрационных проектов

Изображения `*-desktop.jpg`, `*-detail.jpg` и `*-mobile.jpg` сняты с работающих локальных страниц этого репозитория через браузер во время обновления портфолио 22 октября 2026 года. Это снимки интерфейсов, а не макеты или сгенерированные иллюстрации.

- Kosmetica: главная, услуги, мобильная запись.
- FitClub Pro: главная, расписание, мобильное расписание.
- Pulse Merch: главная, каталог, мобильный каталог.
- Orbit Workspace: обзор, канбан-доска, форма редактирования на телефоне.

Десктопные снимки сделаны в окне 1440 × 900; мобильные — 390 × 844. В изображениях присутствуют вымышленные данные демопроектов. Фотографии внутри трёх презентационных сайтов созданы ранее; их происхождение описано в `../assets/README.md`.
