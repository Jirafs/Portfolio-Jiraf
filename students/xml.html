Подготовьте каталог для импорта

  
Создайте каталог с двумя книгами. Корневой элемент — catalog. У каждой книги должен быть уникальный id и непустые элементы title и author.

  
  
  
  
    
  
    Подсказка
    Добавьте автора первой книги, затем создайте вторую запись с новым id.
    

    
  
    Начальный уровень
    
  
    Карточка курса
    
  
    Создайте элемент course с непустым названием в title и укажите язык записи атрибутом lang со значением ru.
    
  
  
  
  
      
  
      Подсказка
      Добавьте lang в открывающий тег course.
      

      

      
  
      Средний уровень
      
  
      Расписание занятий
      
  
      Заполните расписание из двух элементов lesson. У каждого задайте время start в формате ЧЧ:ММ от 00:00 до 23:59 и непустую аудиторию в room. Время начала должно различаться.
      
  
  
  
  
        
  
        Подсказка
        Укажите время атрибутом, например start="09:30".
        

        

        
  
        Продвинутый уровень
        
  
        Связи в электронном каталоге
        
  
        В library создайте разделы authors и books. В authors должны быть две записи author с разными непустыми id. В books должны быть две записи book с непустыми title. Атрибут authorId каждой книги должен ссылаться на существующего автора.
        
  
  
  
  
          
  
          Подсказка
          Значение authorId книги должно точно совпасть с id одного из авторов.
