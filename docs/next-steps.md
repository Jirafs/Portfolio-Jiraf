# Следующие шаги портфолио

Обновлено 26 октября 2026.

## Завершено

- Отдельный локальный Orbit на Python/SQLite: аккаунты, роли, серверные проверки доступа и версии задач.
- Восстановление после конфликта: черновик остаётся в форме, актуальная версия загружается по явному действию пользователя.
- Очистка форм, доски и сведений об аккаунте после выхода или истечения сессии.
- Подтверждение удаления задачи и проверка диапазона числовых ID до обращения к SQLite.
- Регрессионные проверки UI и шесть интеграционных API-тестов.

## Ближайшие доработки

1. Добавить журнал действий в серверный Orbit: кто и когда создал задачу, изменил статус или роль. Записи должны создаваться в одной транзакции с изменением и читаться только участниками пространства.
2. Добавить фильтры задач по статусу и тексту с понятным пустым результатом и сохранением настроек в URL.
3. Обновить визуальный кейс Orbit скриншотами серверной версии и коротким сценарием демонстрации: два аккаунта, роли, конфликт правок.

## Перед внешним размещением сервера

Выбрать хостинг и бюджет, обеспечить HTTPS и Secure-cookie, восстановление доступа, миграции, резервные копии с проверкой восстановления и эксплуатационные ограничения запросов. GitHub Pages продолжает публиковать только статические страницы; локальный API сам по себе там не запускается.
