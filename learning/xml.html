XML и веб-приложения

Опишите данные в XML, проверьте структуру и выведите результат на веб-страницу. Начать можно прямо в браузере.

Перед началом

Основы HTML и JavaScript: строки, массивы, функции и DOM.

Маршрут помогает организовать самостоятельную работу с опубликованными материалами.

Что вы освоите

  • Создавать XML с одним корневым элементом и правильной вложенностью
  • Разбирать XML через DOMParser
  • Выводить данные и объяснять ошибки пользователю

Порядок самостоятельной работы

Пройдите тему по шагам

  1. Устройство XML

    Посмотрите презентацию занятия: корневой элемент, вложенность, атрибуты и регистр имён.

    Попробуйте: Откройте пример «Фильмы» в практикуме и найдите корневой элемент и две записи.

  2. Исправление ошибок

    XML требует закрытых тегов и согласованной вложенности. Сообщение об ошибке помогает найти нарушение структуры.

    Попробуйте: Загрузите ошибочный пример, запустите проверку и исправьте незакрытый тег.

  3. От данных к таблице

    DOMParser создаёт XML-документ. Программа читает поля записей и выводит их как текст в HTML-таблице.

    Попробуйте: Добавьте третью запись, запустите пример и проверьте результат. Затем попробуйте расписание или товары.

Итоговая практика

Что подготовить

Дополните один из трёх примеров до трёх записей с разными названиями. Исправьте ошибки, получите таблицу и скачайте XML. Для самостоятельной работы опишите, как загрузить этот файл через fetch и обработать сбой загрузки.

Выполнить в практикуме ↗

Критерии самопроверки

  • XML разбирается без синтаксических ошибок
  • Корень и поля соответствуют выбранному примеру
  • В файле не менее трёх записей с разными названиями
  • Текст выводится безопасно, ошибки показаны понятным сообщением
