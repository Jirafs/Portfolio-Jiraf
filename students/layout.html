Сверстайте сетку каталога

В поле напишите CSS для .catalog. Требования: две колонки одинаковой ширины, промежуток 16 px. Для экранов до 480 px используйте одну колонку.

    Подсказка

    Используйте grid-template-columns и gap. Для двух равных колонок подойдёт 1fr 1fr.

    Начальный уровень

    Карточка товара

    Оформите .product: внутренний отступ 16 px и скругление 8 px.

      Подсказка

      Используйте padding и border-radius.

      Средний уровень

      Панель действий

      Расположите элементы .toolbar в строку с помощью Flexbox. Разведите их по краям, выровняйте по центру поперечной оси и включите перенос.

        Подсказка

        Проверьте justify-content, align-items и flex-wrap.

        Продвинутый уровень

        Карточка курса с CSS Grid

        Разметьте .course: заголовок занимает первую строку целиком, меню и содержимое делят вторую, подвал занимает третью целиком. Назовите области header, menu, content, footer. На экранах до 600 px расположите области в одну колонку в том же порядке.

          Подсказка

          Укажите grid-template-areas и grid-template-columns. Для широкого экрана подойдут 1fr 2fr.
