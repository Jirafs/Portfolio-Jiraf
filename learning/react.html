01 / Компоненты и состояние

Разработка на React

Соберите интерфейс из компонентов, добавьте поиск и научитесь управлять состоянием приложения.

Материалы для скачивания ↓Перейти к заданию

Перед началом

HTML, CSS, функции и массивы JavaScript, обработчики событий.

Маршрут помогает организовать самостоятельную работу с опубликованными материалами.

Что вы освоите

  • Разбивать интерфейс на компоненты и передавать props
  • Управлять состоянием и отображать списки
  • Показывать загрузку, ошибки и пустые результаты

Порядок самостоятельной работы

Пройдите тему по шагам

  1. Компоненты и JSX

    Изучите разделы пособия о JSX и компонентах. Разделите карточку учебного материала на заголовок, описание и действия.

    Попробуйте: Соберите три карточки из массива данных. Используйте устойчивые ключи элементов.

  2. Props и состояние

    Передайте данные карточкам через props. Добавьте useState для строки поиска и выбранной категории.

    Попробуйте: Сделайте поиск по названию и совместимый фильтр по категории.

  3. Данные и состояния интерфейса

    Разберите работу с эффектами и загрузкой данных в пособии. Продумайте поведение при ожидании, ошибке и пустом списке.

    Попробуйте: Добавьте понятное сообщение об ошибке и кнопку повторной загрузки.

  4. Небольшой проект

    Объедините компоненты, фильтры и работу с данными в каталог учебных материалов.

    Попробуйте: Проверьте каталог с клавиатуры и на узком экране.

Итоговая практика

Что подготовить

Каталог учебных материалов с поиском, категориями и состояниями загрузки. Подготовьте исходный код и короткое описание принятых решений.

Критерии самопроверки

  • Компоненты имеют понятные задачи, данные передаются через props
  • Поиск и категория работают вместе
  • Есть загрузка, ошибка с повтором и пустой результат
  • Поля подписаны, интерфейс доступен с клавиатуры и на телефоне
