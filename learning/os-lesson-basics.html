Коротко о главном

Приложение и службы системы

Редактор формирует содержимое документа, а операционная система предоставляет доступ к ресурсам: памяти, файлам и устройствам. Обращение к службам ОС идёт через программные интерфейсы. API — договор о способе обращения; не каждый вызов API обязательно приводит к отдельному системному вызову.

Ядро и режим выполнения

Ядро управляет ключевыми ресурсами системы. В Windows обычные приложения работают в пользовательском режиме, а основные компоненты ОС — в режиме ядра. Такое разделение ограничивает доступ приложений к системным данным. Многие драйверы работают в режиме ядра, но существуют и драйверы пользовательского режима.

Драйвер и файловая система

Драйвер обеспечивает взаимодействие с конкретным устройством. Файловая система организует имена, каталоги и размещение данных. Сохранение файла задействует несколько механизмов; один компонент не выполняет всю работу самостоятельно.

Разобранный пример

Редактор сохраняет report.txt

Пользователь нажимает «Сохранить». Рассмотрим упрощённый путь запроса, без деталей кэширования.

  1. Редактор подготавливает текст и обращается к интерфейсу записи файла.
  2. ОС проверяет доступ и передаёт запрос механизмам файловой системы.
  3. Если требуется ввод-вывод, соответствующие драйверы обеспечивают работу с устройством.
  4. Приложение получает результат операции и показывает успех или ошибку.

Успешная запись через API и физическое сохранение на носителе — разные этапы: между ними могут находиться буферы. Здесь важно правильно распределить роли компонентов.

Самостоятельная работа

Примените на практике

Опишите, что происходит при открытии фотографии с диска и её показе в приложении.

  • Назовите минимум четыре участника: приложение, ОС, файловую систему и драйвер.
  • Для каждого укажите его задачу и данные, которые он получает.
  • Добавьте ветку «доступ запрещён»: где выполняется проверка и что должно показать приложение?

Что подготовить

Схема из 5–7 шагов и короткое объяснение отказа в доступе.

Ответ подготовьте в своём документе или тетради. Эта страница не отправляет работу преподавателю.

Критерии проверки

  • Прикладная обработка изображения отделена от управления ресурсами.
  • Драйвер связан с устройством, файловая система — с хранением и именами.
  • Ошибку доступа обрабатывают без обхода проверки прав.

Проверьте понимание

Почему графический редактор не является операционной системой?

Редактор решает прикладную задачу и пользуется службами ОС. Он не заменяет системное управление памятью, устройствами и выполнением остальных программ.

API и ядро — одно и то же?

Нет. API описывает доступные программные операции. Ядро — компонент ОС, реализующий управление привилегированными ресурсами. Часть функций API выполняется в пользовательском пространстве.

Частая ошибка. Не приписывайте ядру все действия приложения: форматирование документа и выбор его содержимого выполняет редактор.

Отметку вы ставите самостоятельно после выполнения задания. Она хранится в текущем браузере и не является оценкой.
