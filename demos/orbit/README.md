# Orbit Workspace

Сложное клиентское демо для портфолио Jiraf. Пять экранов: обзор, канбан, аналитика, команда и управление пространством. Команда и задачи вымышлены.

## Возможности

- Создание, редактирование и удаление задач; перенос между четырьмя статусами мышью или через доступную форму.
- Проекты, исполнители, приоритеты, сроки, оценка времени и чек-листы.
- Совместимые фильтры и поиск; аналитика рассчитывается из выбранных задач.
- Создание проектов и участников, история операций, локальное сохранение.
- JSON-экспорт и импорт с проверкой версии, ссылок между сущностями, дат, уникальности ID и ограничений размера.
- Обновление вкладок через событие storage и обнаружение изменения редактируемой задачи.
- Клавиши N (новая задача), / (поиск), Escape (закрыть диалог). В полях эти команды не перехватывают ввод.

## Устройство

`model.js` содержит доменную модель, валидацию, операции над задачами и производные показатели. `store.js` перечитывает сохранение перед записью, проверяет конфликты редактирования и сохраняет повреждённый оригинал для восстановления. `ui.js` содержит безопасные DOM-хелперы и диалог подтверждения с возвратом фокуса. `app.js` связывает интерфейс, фильтры, формы и файлы. Все пять HTML-страниц используют одну модель и ключ `jiraf.orbit.v1`. Ввод отображается через textContent.

У каждой карточки есть выбор статуса для телефона и клавиатуры. Конфликт правок в двух вкладках отклоняется с сообщением; localStorage не обеспечивает атомарные транзакции между процессами и не заменяет серверную совместную работу. При запрете сохранения изменения остаются в памяти вкладки, доступен экспорт. Повреждённое сохранение можно скачать исходным файлом перед восстановлением демоданных.

Это демонстрация фронтенд-разработки: сервер, аккаунты, реальные уведомления, права доступа и совместная работа между устройствами не подключены. Участники — сущности демо, а не авторизованные пользователи. Оценка времени вводится вручную и не означает фактическое отработанное время.

Проверка модели: `node tests/orbit-model.cjs` из корня портфолио. Скриншоты в `../screens/` сняты с работающих локальных страниц; фотографии в других демо имеют отдельное происхождение в документации соответствующих ресурсов.

## Отдельная серверная версия

В fullstack.html — интерфейс и инструкция запуска Python-сервера с SQLite, аккаунтами, ролями и контролем версий задач. Она использует отдельную модель и базу. Подробности и API-тесты — в server/README.md. Существующее клиентское демо продолжает работать локально в браузере.
